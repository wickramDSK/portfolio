## 🚦 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository

```bash
git clone https://github.com/wickramDSK/My-Portfolio.git
```

2. Navigate to project directory

```bash
cd My-Portfolio
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open `http://localhost:5173` in your browser

## 💻 Development

### Available Scripts

- `npm run dev`: Starts development server
- `npm run build`: Creates production build
- `npm run preview`: Preview production build locally

## 📱 Responsive Design

The portfolio is fully responsive and optimized for:

- Desktop (1200px and above)
- Tablet (768px to 1199px)
- Mobile (below 768px)

## 🔧 Customization

You can customize the portfolio by:

1. Modifying content in component files
2. Adjusting styles in `Styles.css`
3. Adding new components as needed
4. Updating images in the assets folder
